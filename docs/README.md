# BioLibrary Frontend Docs

> Documentación completa y navegable del frontend del sistema BioLibrary.

---

## Introducción

BioLibrary es un sistema de préstamo digital de libros para una red de universidades, donde las licencias de cada libro son limitadas y se aplican reglas estrictas de acceso y revocación. El frontend está desarrollado en Next.js y se integra con un backend de microservicios Java.
